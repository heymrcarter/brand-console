# Foundations

These are the basic choices every component is built from. The Brand Console sets all of them. Do not copy the values into an app by hand. Use `theme.css` instead, so apps change when the brand changes. This design system is for our own teams only.

## Color

Each brand has three colors: a **main color**, a **second color**, and an **accent color**. The main color is used for buttons, links, and the keyboard focus outline. The second color is used for tags, badges, and selected rows. The accent color is for small touches like charts. It is never used for words.

Components never use these colors directly. They use **roles**, like `--primary`, `--foreground`, `--muted-foreground`, and `--destructive-text`. The console works out each role from the brand colors, for light and dark mode. The role names match shadcn, so most shadcn parts pick up the brand on their own.

Rules that never change:

- Words must have a contrast of at least 4.5 to 1 with what is behind them. 7 to 1 is best for our members, because most are over 65. The console blocks a publish that breaks this.
- Never use color alone to say something. An error has an icon and words, not just red.
- Error words use `--destructive-text`, not `--destructive`.

## Type

Each brand picks a font for headings, one for body text, and one for labels and buttons. `settings.json` has a link that loads them. Body text has a roomy line height (1.5 to start), so lines do not crowd each other. Heading sizes grow by the same step, called the type scale.

Use plain words at a fifth-grade reading level, in full sentences. Labels sit above boxes, never inside them.

## Screen types and text sizes

There are two screen types, and each has two text sizes. Put them on `<html>` with `data-screen` and `data-size`.

- **Consumer** screens are for members, on any device. They have large text, big buttons, and lots of space.
- **Employee** screens are for our staff, at a desk. They have smaller text, so more fits on the screen.

Each screen type has a standard and a large text size. Large makes text and controls about 1.12 times bigger. The admin team sets the sizes. Brand teams cannot change them. Anything people press must be at least as tall as `--control-h`.

## Light and dark mode

Put `data-mode="light"` or `data-mode="dark"` on `<html>`. Every role has a light and a dark value, and both are checked for contrast. Dark mode is not just light mode turned upside down. The console picks dark colors that keep the brand and stay easy to read.

## Using the values outside of CSS

`dist/tokens.resolved.json` has every final color and size, for tools that cannot read CSS. The token files in `tokens/` follow the W3C design tokens format and are the source of truth.
